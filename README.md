
A high-performance, cross-platform desktop image editing tool built with C# and .NET.

This project serves as a practical implementation of pure software engineering principles, focusing on low-level memory management, matrix mathematics for image convolution, and architectural design patterns (MVVM, Command Pattern) without relying on automated AI models.

## Technology Stack

* **Framework:** [.NET 8.0](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
* **UI Architecture:** [Avalonia UI](https://avaloniaui.net/) (Cross-platform XAML)
* **Graphics/Processing:** SkiaSharp / SixLabors.ImageSharp
* **Design Pattern:** MVVM (Model-View-ViewModel)

## Getting Started

### Prerequisites

* .NET 8.0 SDK installed on your system.
* A terminal or IDE (Rider, VS Code, Neovim) to run the build commands.

### Installation & Execution

1. **Clone the repository:**

   ```bash
   git clone <your-repository-url>
   cd MyImageEditor

```

2. **Restore dependencies:**
```bash
dotnet restore

```

1. **Run the application:**

```bash
dotnet run

```
